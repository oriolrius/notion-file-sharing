NFS 2.2.1: the `nfs` CLI is now **all in English**.

## Fix

- The input errors of `nfs create` (URL, expiry, alias) were in Catalan, and the rest of the CLI was
  in English. Now every CLI message is in English, for example:
  `Error: the URL has no block id (#…): copy the link to the block, not to the page`.
- The web pages do not change: Catalan, Spanish and English with the selector (2.2.0).
