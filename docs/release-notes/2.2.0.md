NFS 2.2.0 adds a **language selector** to the web pages: Catalan, Spanish and English.

## Highlights

- Every page is translated: the link generator (`/_/`), the password page of protected links and
  the error pages that viewers see (link not found, link expired, temporary errors, login errors).
- The language comes from the browser (`Accept-Language`) by default. The **CA · ES · EN** selector
  in the header changes it and keeps the choice for one year (cookie `nfs_lang`). After the change,
  the same page opens again. The selector works without JavaScript.
- The URL field of the generator no longer shows part of a real Notion block id as an example.

## Compatibility

- No change to the links: v1 and v2 links, keys and the Notion/Kutt calls are the same.
- The CLI messages stay in Catalan.
